I built **Easy Payments** to give developers reusable checkout components they can fit into their own applications. The Angular package lets you choose which payment methods to show and in what order. Your application defines the product, price, currency, and order flow.

| Checkout mode | What it gives you |
| --- | --- |
| **Full Checkout** | A ready-to-use checkout with a product summary and payment method selection. |
| **Buttons Only** | Payment controls you can add to a checkout you already built. |
| **Headless** | Checkout sessions and payment events for building your own interface. |

### What's new

- **v1.2.0** introduced Headless Checkout and expanded Buttons Only for custom checkout flows.
- **v1.2.1** added the official website to the npm package metadata and project READMEs.
- The **project website** brings together versioned documentation, an interactive playground, localized checkout screenshots, and a contact form.

### Try it in your Angular app

```bash
npm install @easy-payments/angular @stripe/stripe-js
```

Start with mock mode to explore the checkout without payment credentials. The package also supports **light, dark, and system themes**.
