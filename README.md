## 🚀 Recent Project

### 💳 Easy Payments

[![npm version](https://img.shields.io/npm/v/@easy-payments/angular.svg)](https://www.npmjs.com/package/@easy-payments/angular)
[![npm downloads](https://img.shields.io/npm/dm/@easy-payments/angular.svg)](https://www.npmjs.com/package/@easy-payments/angular)

📦 **Available on npm:** [@easy-payments/angular](https://www.npmjs.com/package/@easy-payments/angular)

**Easy Payments** is a modern Angular payment library designed to make payment integrations simple, flexible, and developer-friendly.

The project focuses on providing a **plug-and-play checkout experience**, allowing developers to integrate multiple payment methods without having to build the entire payment interface and integration flow from scratch.

Developers remain in control of their own checkout configuration, including products, prices, currencies, payment methods, payment order, and application flow, while Easy Payments handles the reusable payment experience.

### ✨ Current Highlights

- Angular & TypeScript library architecture
- Plug-and-play payment components
- Stripe payment integration
- PayPal integration
- Google Pay support
- Configurable payment methods and display order
- Light, dark, and system themes
- Developer-defined products, prices, and currencies
- NestJS backend integration for secure payment processing
- Automated unit and integration testing
- Extensible architecture for additional payment providers and methods

The goal is simple: **make adding payments to an Angular application as easy as possible while keeping developers in control of their business logic.**
