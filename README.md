I built Easy Payments to give Angular developers reusable checkout components and the flexibility to fit them into their own apps. Your application defines the products, prices, currencies, payment methods, and order flow.

Three ways to integrate

Mode	What you get
Full Checkout	A ready-to-use checkout with a product summary and payment method selection.
Buttons Only	Payment controls you can add to an existing checkout.
Headless	Checkout sessions and payment events for building your own interface.

Configure which payment methods appear and in what order, choose a light, dark, or system theme, and try each checkout mode with simulated payments. The project includes Stripe and PayPal integrations, a Google Pay test flow, and a NestJS backend example.
